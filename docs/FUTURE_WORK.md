# Research planned after the semester

The work below has been discussed as a direction for continuing the project after the semester. None of it is claimed as a completed result.

1. Test stricter critical alert protection, especially severity 10, without changing the original benchmark.
2. Add stronger coverage preserving comparators such as weighted greedy selection, reverse deletion and exact optimization on small groups.
3. Extend evidence requirements to include more entity details and stronger relationship checks.
4. Measure false merges and false splits using independently labeled incident relationships.
5. Repeat the evaluation across longer windows and other approved workloads.
6. Study actual analyst investigation time and decision quality through controlled user testing.
7. Explore risk aware selection and safe adaptation with explicit update gates.
8. Develop a publication focused evaluation with stronger baselines and independent validation.

The existing source code and results are the semester baseline for this continued work.
